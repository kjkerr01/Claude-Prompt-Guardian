# Claude-Prompt-Guardian
Intercepts prompts going to Claude's servers and checks them for under-18 content, which could lead to you being banned, and prevents your prompt from reaching anthropic if there is.

# How to use:
Download all files to a folder on your computer\
Go to chrome://extensions/ (or the extension page of whatever browser you use)\
Turn on developer mode\
Select load unpacked\
Select your folder with the files\
Wait for it to load, and then go to Claude and test it out (your responses may take longer than normal)
